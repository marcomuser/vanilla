# Decisions

We explore architecture ideas with throwaway prototypes. Each exploration ends
in one decision, recorded here. Its prototype is then deleted.

A decision record is short and self-contained. It states what we decided and
why, at an architectural level, and lists the alternatives we rejected.
Implementation details belong in code and skills, not here.

## Format

```markdown
# NNNN Title

## Context        The question and its constraints.
## Decision       What we do.
## Rationale      Why. The few findings that settled it.
## Consequences   What we accept.
## Alternatives   One line each, with the reason it lost.
```
